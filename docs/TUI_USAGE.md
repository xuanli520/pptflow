# Harbor Flow TUI 使用指南

Harbor Flow 的终端界面以中文为主，并保留少量英文业务标识，方便与日志和工件字段对应。

## 全局导航

以下导航键适用于运行视图；启动表单为避免误离开未提交配置，只启用其底部列出的表单键位和 `?` 帮助。

| 键位 | 操作 |
|---|---|
| `Ctrl+O` | 总览 |
| `Ctrl+G` | 当前审查关卡；没有活跃关卡时显示提示 |
| `Ctrl+D` | 节点详情 |
| `Ctrl+L` | 日志 |
| `Ctrl+E` | 完成页；运行未结束时显示提示 |
| `Ctrl+X` / `x` | 取消运行，执行前确认 |
| `q` / `Ctrl+Q` / `Ctrl+C` | 退出；运行中执行前确认 |
| `/` | 在总览、详情或日志中搜索/过滤 |
| `?` | 打开或关闭快捷键帮助 |
| `Esc` | 关闭弹窗、结束备注编辑或返回总览 |

数字键 `1`–`4`、`d`、`g` 和 `l` 继续兼容旧版导航。

## Tab 行为

`Tab` 始终表示“当前上下文中的下一个项目”，`Shift+Tab` 表示上一个项目：

- 启动表单：切换字段；
- 总览和完成页：切换页面；
- 审查页和节点详情：切换工件；
- 日志页：切换日志文件。

当前上下文允许的操作始终显示在底部帮助栏中。

## 启动表单

启动表单是两步向导。第一步只填写运行模式、任务或仓库来源以及工作区，按 `Enter` 进入高级选项；第二步在 Harbor 配置、质量与相似度、结果与打包、任务与代理四组之间切换，按 `Enter` 验证并启动。

高级选项一次只展开一组。使用 `F1`–`F4` 或 `Ctrl+←`/`Ctrl+→` 切换分组，`Esc` 返回基本配置；`Space` 切换布尔项，`Ctrl+U` 清空文本字段。

启动表单中使用 `Ctrl+Q` 退出；普通的 `q` 会在文本字段中正常输入。

文本字段支持光标移动、插入编辑、粘贴和中文输入法。路径字段按 `Ctrl+Space` 自动补全；有多个候选时补全公共前缀并显示候选摘要。

## 审查和日志

审查页使用 `a`/`Ctrl+A` 批准、`r`/`Ctrl+R` 拒绝、`v`/`Ctrl+V` 修订或刷新、`Ctrl+N` 编辑多行备注、`e` 编辑工件。批准、拒绝和编辑工件都必须在确认框中再次确认。

日志页使用 `↑`/`↓` 或 `j`/`k` 逐行滚动，`PgUp`/`PgDn` 翻页，`Home`/`g` 跳到顶部，`End`/`G` 跳到底部，`t` 切换尾部自动跟踪。页面底部会显示当前行范围和滚动百分比。
